# niri-dms-dots
My Niri and DMS dotfiles

Installation: Copy the dots (all files and folders in this git repo)
Packages needed:
- If on Gentoo: Add the GURU overlay and install: niri dankmaterialshell xwayland-satellite matugen alacritty
- If on a Arch-based distro: niri dms-shell xwayland-satellite matugen alacritty
