My Niri and DankMaterialShell Dotfiles

Installation: git clone this repo and copy everything in the root of the git repo and run: systemctl --user add-wants niri.service dms.service

Needed Packages: 
- If on Gentoo: Add the GURU overlay and install: niri dankmaterialshell xwayland-satellite matugen qt6ct alacritty
- If on a Arch-based distro: Install: niri dms-shell xwayland-satellite matugen qt6ct alacritty
